# 多包装组合展示设计

## 1. 目标

在不增加“场景”或其他设置区域的前提下，让用户把最多六个包装放入同一个 3D 棚拍场景。组合允许不同包装类型混排，也允许同一类型重复添加并分别使用不同图稿、工艺和尺寸。

首版解决自动添加、选择、排列、接地、间距、相机取景、保存和导出，不提供单个包装的自由位置编辑。

## 2. 已确认的产品范围

- 一个项目包含一至六个独立包装实例。
- 保留现有四个设置区域：贴图、工艺、盒型、相机。
- 每个包装类型按钮后增加 `+`。点击后把该类型的新实例加入左侧 3D 预览。
- 不同包装类型可以混排；同类型可以重复添加。
- 每个实例拥有独立图稿、工艺、尺寸、结构状态和唯一 ID。
- 最后一个实例不能删除；达到六个后禁用所有新增按钮并显示数量限制。
- 旧项目打开后迁移为仅包含一个实例的新项目。

## 3. 新增实例

新增实例复制该包装类型现有实例的尺寸与结构设置，但图稿和工艺蒙版保持空白。这样用户可以快速建立同规格、不同设计的系列包装，同时不会误认为两个实例共享图稿。

新实例加入后立即成为当前选中实例。相同类型按添加顺序显示名称，例如“六面盒型 1”“六面盒型 2”。名称仅用于界面识别，不改变包装类型。

## 4. 当前实例选择与编辑

采用双入口选择：用户可以点击左侧 3D 模型，也可以点击右侧设置区域顶部的包装实例列表。选中状态在 3D 预览和列表中同步显示。

贴图、工艺和盒型区域只编辑当前实例。相机区域继续控制整个组合场景。实例列表属于现有设置界面的公共选择器，不形成第五个设置区域。

删除当前实例后，选择列表中相邻的可用实例。删除操作触发组合重新排列。仅剩一个实例时隐藏删除入口或将其禁用。

## 5. 排列方式

保留四种用户可选预设：

- A：主品居中。中心主包装强调展示，两侧围绕主品排列。
- B：系列平铺。统一基线和均匀视觉节奏，适合两个包装和产品家族。
- C：错落组合。通过水平位置、深度和轻微朝向差异建立空间感，但所有包装仍在地面上。
- D：双排阵列。前后两排紧凑陈列，适合五至六个包装。

数量对应的默认预设为：

- 一个包装：使用现有单包装居中预览，不显示排列选择。
- 两个包装：默认 B。
- 三至四个包装：默认 C。
- 五至六个包装：默认 D。

两个及以上包装均可手动切换 A、B、C、D。新增或删除实例后，系统根据新数量重新采用推荐预设；仅修改实例尺寸时保留用户当前预设，只重新计算布局。

A 预设在用户切换进入时，把当时的当前实例设为中心主品；随后仅切换编辑对象不会改变主品或触发布局跳动。B、C、D 使用实例添加顺序作为稳定排序，删除后保留剩余实例的相对顺序。

## 6. 真实尺寸与自动布局

包装体积只由盒型尺寸和模型结构决定。上传图片的像素尺寸、画布尺寸和比例不得改变几何体大小；低分辨率图片只产生清晰度提示。

布局引擎在模型加载和尺寸变形完成后读取每个实例变换后的世界空间包围盒，并依次执行：

1. 以实例最低点对齐统一地面。
2. 按当前预设确定前后排、左右顺序和允许的水平朝向。
3. 根据实际宽度和深度计算外轮廓安全间距。
4. 检测并消除包围盒穿插。
5. 重新居中完整组合。
6. 根据组合边界调整相机目标、距离和裁剪范围，确保所有包装完整进入画面。

任何预设都不得使用垂直错层或悬空。尺寸差异较大时仍保留真实比例，小包装不得为了构图被暗中放大。

实例尺寸、模型开合状态或其他会改变边界的结构参数发生变化时，重新运行以上流程。重排移动的是系统生成的位置，不改写用户的尺寸和图稿参数。

## 7. 光照与阴影

所有实例共享现有棚拍灯光和环境光，并继续向地面及其他允许接收阴影的对象投影。

所有包装保留 `castShadow`。普通低密度结构可以接收方向灯阴影；现有高密度模型继续使用 `receiveShadow={false}`，避免重新出现与三角剖分一致的自阴影条纹。组合场景使用统一接触阴影增强落地感。

首版不增加实时全局光照、颜色反弹或动态对象间镜面反射。目标是获得可信的同棚拍摄效果，同时保持现有包装表面质量和网页性能。

## 8. 加载、失败与边界状态

- 新模型加载期间保留当前组合，并显示该实例的加载状态。
- 只有模型和尺寸边界可用后才把新实例加入布局，避免用错误边界产生跳动或穿插。
- 模型加载失败时不加入组合，显示明确错误，并保留原组合。
- 自动排列不得突破各包装类型原本允许的尺寸范围。
- 达到六个实例后禁用所有新增按钮；删除到五个后恢复。
- 图片分辨率不足不阻止加入组合，只提示可能影响导出清晰度。

## 9. 数据、保存与导出

项目状态改为包装实例列表，并保存当前实例 ID、排列预设和全局相机设置。每个实例通过包装类型联合对应的独立状态载荷恢复自身图稿、工艺、尺寸和结构状态。

透明 PNG 导出复用当前场景、灯光强度、排列和投影选项，输出完整组合。导出相机必须使用完整组合边界进行取景，不能裁掉后排或极端尺寸包装。

首版可以在实例模型中保留未来手动变换的数据位置，但不得在 UI 中暴露位置、高度或 XYZ 控件，也不得让未启用的字段影响自动排列。

## 10. 验收标准

### 功能

- 可以添加不同包装类型并同时显示。
- 可以添加两个相同类型，分别上传不同图稿并调整不同尺寸，状态互不影响。
- 第六个实例可以添加，第七个实例不能添加。
- 左侧 3D 点击和右侧列表均能切换当前实例。
- 添加、删除、保存、打开和旧项目迁移不丢失实例状态。
- PNG 导出包含全部实例和当前排列。

### 自动布局

- 一个实例保持现有居中预览。
- 两个、三至四个、五至六个实例分别得到 B、C、D 默认预设。
- 两个以上实例均可手动切换四种预设。
- 修改任一实例尺寸后保持当前预设，其他实例自动让位。
- 不同尺寸和不同类型混排时没有模型穿插。
- 所有实例最低点位于同一地面，A、B、C、D 均无悬空。
- 重排后完整组合保持居中，所有包装都在相机画面内。

### 视觉与回归

- 桌面端验证一至六个实例的四种排列、设置面板滚动和当前实例状态。
- 移动端验证完整取景、正常文档滚动、实例选择和新增上限。
- 用极大与极小包装混排验证真实比例、接地、间距和相机取景。
- 高密度模型在组合阴影下不重新出现三角形自阴影条纹。
- 现有单包装贴图、工艺、盒型、相机和透明 PNG 行为保持不变。

## 11. 后续范围

未来可以增加手动位置、旋转、构图锁定或自定义排列，但不属于本次首版。后续能力必须建立在独立包装实例上，不能破坏自动排列和统一接地规则。
