# 六面盒表面工艺设计规格

## 目标

在现有“工艺”标签中完整加入六面盒表面工艺，并保持贴图、盒型、相机、自立袋和内包装1的现有配置与行为不变。

## 范围

- 仅当包装类型为 `box` 时显示工艺设置。
- 支持五种可叠加工艺：烫金、烫银、镭射、UV亮膜、击凸/压凹。
- 每种工艺拥有独立显示开关、材质参数、六面黑白蒙版和清空操作。
- 每张工艺蒙版拥有独立的缩放、水平位置、垂直位置和旋转参数，并提供重置。
- 工艺状态接入撤销、重做、新建、保存、打开和透明 PNG 导出。

## 不在范围内

- 不支持刀模拆面、批量自动识别或自动分配。
- 不把工艺应用到 `pouch` 或 `inner-packaging-1`。
- 不修改现有印刷贴图、盒体尺寸、相机或导出入口。
- 不增加场景、AI 或“按住查看无工艺”等入口。

## 面板结构

工艺页复刻参考站的信息层级：

1. `FINISH / 表面工艺 / 多工艺叠加` 标题区。
2. 五张工艺选择卡。选择卡仅切换当前编辑层，不影响其他工艺状态。
3. 当前工艺显示开关。关闭后保留蒙版和参数，只停止渲染该层。
4. 当前工艺参数卡，包含数值输入、同步滑块和恢复默认值。
5. 六面工艺蒙版上传区，面顺序保持 `top / left / front / right / back / bottom`。
6. 选中已上传蒙版后显示贴图变换区：缩放、水平位置、垂直位置、旋转和重置。
7. 清空当前工艺层只移除当前层的六张蒙版，不影响其他工艺或印刷贴图。

## 工艺参数

- 烫金、烫银：表面粗糙度、箔面细纹、微表面法线、凹凸强度。
- 镭射：表面粗糙度、虹彩强度、凹凸强度。
- UV亮膜：表面粗糙度、亮膜强度、凹凸强度。
- 击凸/压凹：表面粗糙度、凹凸强度。
- 凹凸强度小于 0 表示压凹，大于 0 表示击凸，等于 0 表示平面。
- 每种工艺有固定默认参数；恢复默认值不删除蒙版。

## 蒙版与变换规则

- 支持 PNG、JPEG、WebP，沿用现有图片校验和本机 Data URL 读取流程。
- 黑色或非白色像素定义完整不透明的工艺覆盖区域，白色像素透明；灰度内部细节不得变成半透明图像。
- 每张蒙版变换相互独立，不与基础印刷贴图共享变换状态。
- 缩放范围为 50%–300%；水平和垂直位置范围为 -100%–100%；旋转范围为 -180°–180°。
- 变换以对应盒面中心为基准。超出蒙版图像的区域保持无工艺，不重复平铺、不拉伸边缘。
- 重置恢复 100% 缩放、0% 水平位置、0% 垂直位置和 0° 旋转。
- 面板变换、3D 预览和透明 PNG 导出必须使用同一组纹理矩阵，避免预览与导出不一致。

## 渲染设计

现有六个基础印刷材质保持不变。每个盒面在同一几何位置叠加工艺覆盖层，由当前面的工艺蒙版控制透明度。覆盖层沿面法线做极小偏移以避免 Z-fighting，不改变盒体尺寸、圆角或相机。

工艺按固定顺序组合：UV亮膜、烫金、烫银、镭射、击凸/压凹。颜色类工艺只覆盖蒙版区域；凹凸参数同时驱动材质法线/位移近似，使光照变化在旋转盒体时可见。实现以浏览器实时预览稳定性为优先，不生成生产级压印几何。

## 状态与兼容

项目状态新增 `boxFinish`，包含五个工艺层。每层保存：显示状态、材质参数、六面蒙版；每张蒙版保存资产信息与独立变换。

项目文件版本递增。打开旧版本项目时自动补齐默认空工艺状态，原有三种包装数据不得丢失。所有工艺修改通过现有 history reducer 提交，以支持撤销和重做。

## 错误处理

- 图片类型、尺寸或读取失败时，在对应面显示错误，不修改已有蒙版。
- 非有限数值或超出范围的变换与材质参数由 reducer 拒绝。
- 工艺纹理加载失败时保留基础印刷层，避免盒面变黑或消失。

## 验收标准

### 镭射专项标准

- 以用户提供的参考站截图为唯一视觉事实源。
- 蒙版内部必须完全覆盖原包装图案，不得透出人物五官、衣服或其他灰度细节。
- 膜色必须呈现大面积连续的紫、蓝、青、绿柔和过渡，并保留金属高光与视角变化。
- 蒙版边界保留抗锯齿，区域外的原包装完全不变。

- 五种工艺均可选择、开关、调参和恢复默认值。
- 每种工艺均可独立上传六面蒙版，多层可同时显示。
- 调整任一蒙版的大小、旋转和位置时，3D 对应盒面实时变化，其他面和其他工艺不变。
- 蒙版空白外区域无平铺、无边缘拉伸、无整面错误覆盖。
- 工艺变化可撤销、重做、保存、打开和新建重置。
- 透明 PNG 导出与当前 3D 工艺状态一致。
- 自立袋和内包装1的现有贴图、参数、渲染与保存行为通过回归测试。
- 通过类型检查、lint、单元测试、生产构建和 Sites Worker 测试。
- 在桌面与 390×844 视口真实检查面板溢出、遮挡、交互和 3D 可见效果。

## 风险与取舍

- 多层透明 PBR 覆盖会增加 draw call；最多 30 个面工艺层，空蒙版层必须不创建材质或 mesh。
- `MeshStandardMaterial` 无原生虹彩参数时需使用物理材质或小型 shader 扩展；实现必须保持可维护，避免把五种工艺塞进一个难以测试的巨型 shader。
- 击凸/压凹是实时视觉近似，不等同于生产模型真实几何变形；本产品目标是包装效果预览，不是制造文件输出。
