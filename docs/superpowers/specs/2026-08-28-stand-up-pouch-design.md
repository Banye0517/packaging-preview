# BoxLab 自立袋设计规格

## 目标

在不修改现有六面盒型行为的前提下，新增三边封自立袋包装类型。用户选择自立袋后，首页三维舞台显示自立袋模型；上传正面和背面图片后，图片分别映射到对应袋面。用户可设置袋体厚度、四角圆角，以及互斥的无封口、拉链或顶部居中吸嘴。

## 范围边界

- 保留且不重写现有六面盒型、六面上传、尺寸、相机和导出行为。
- 设置区仍保持且仅保持贴图、工艺、盒型、相机四个区域。
- 不增加场景或 AI 区域。
- 自立袋只上传正面和背面，不增加侧面或底面图片上传；底部固定为白色。
- 不做软体物理模拟、随机褶皱、刀版拆分或自动面分配。

## 页面行为

“盒型”设置区顶部增加包装类型选择：六面盒型和自立袋。默认类型为六面盒型。

选择自立袋时：

- 首页三维舞台加载自立袋模型。
- “贴图”区只显示正面、背面两个上传入口。
- “盒型”区显示袋宽、袋高、袋体厚度、底部展开深度、四角圆角开关和封口类型。
- 封口类型为互斥单选：无封口、拉链、吸嘴。
- 吸嘴固定在顶部中央。

两种包装类型各自保留贴图与尺寸状态。来回切换不能清空另一类型的数据或改变相机位置。

## 三维结构

自立袋采用参数化三边封结构：

- 只有正面和背面两张可印刷曲面。
- 左、右和顶部生成具有真实前后厚度的窄热封边；封边使用连续圆弧截面连接正背片，形成柔和高光与圆润边缘，不能表现为两张平面纸片直接拼接。左右封边不是独立侧面，也不承载贴图。
- 底部不生成封死的横向封边，而是生成向外撑开的风琴折叠面，使模型能够站立。
- 底部风琴面固定使用白色。
- 正背面使用轻微、确定性的薄膜弧度表达软包装质感，不使用随机形变。
- 四角圆角开关同时控制正背片外轮廓四角；关闭后恢复直角，底部仍保持撑开的风琴结构。
- 拉链状态在顶部封边下方生成两条可见横向凸条。
- 吸嘴状态在顶部中央生成短颈和旋盖，顶部封边在连接位置合理断开。
- 无封口状态只显示三边热封结构。

袋宽、袋高、袋体厚度、底部展开深度、圆角和封口状态变化时重建相关几何体，但不得重置贴图或相机状态。袋体厚度控制正背片距离和三边封边圆弧截面的深度；底部展开深度独立控制站立风琴的最大展开量。

## 贴图

正面和背面沿用现有图片合同：仅接受 PNG、JPEG、WebP，验证非空、可解码、非零尺寸和 4000 万像素上限，所有数据只在浏览器本地处理。

## 状态与项目兼容

项目状态增加当前包装类型和独立的自立袋状态，包括正背面资源、袋宽、袋高、袋体厚度、底部展开深度、四角圆角和封口类型。底部白色属于固定渲染合同，不进入可编辑项目状态。

Undo/Redo、重置、保存、打开和透明 PNG 导出必须支持两种包装类型。保存文件包含两套状态。旧版 `version: 1` 项目打开时迁移为六面盒型，并为自立袋填充默认状态；迁移不能丢失原六面贴图和盒体参数。

## 错误处理

- 自立袋图片校验失败时保留当前有效图片。
- 非法或非正数尺寸不进入项目状态。
- 纹理或几何体替换时释放旧 Three.js 资源，避免切换类型后持续占用显存。
- 打开损坏或不兼容项目文件时保留当前项目并显示明确错误。

## 验收标准

- 默认进入六面盒型，现有六面上传与三维模型行为不变。
- 六面盒型与自立袋来回切换时，两套数据分别保留。
- 选择自立袋后首页显示可旋转、缩放和固定视角查看的三边封模型。
- 正面、背面上传后分别映射到正确袋面，左右封边没有独立贴图。
- 底部为撑开的白色风琴结构，不显示封死的横向底边。
- 调整袋体厚度时，正背片距离和上、左、右封边圆弧厚度同步变化；三条封边始终连续连接正背片，不出现双层纸片拼接感。
- 四角圆角开关能明显改变四个外轮廓角。
- 无封口、拉链、顶部居中吸嘴严格互斥，模型结构与当前选择一致。
- 自立袋尺寸或结构选项变化不清空贴图或相机位置。
- 旧项目文件按六面盒型成功打开且数据完整。
- 当前三维视图可导出 2000×2000 透明 PNG。
- 桌面和 390×844 视口无文字截断、控件遮挡、画布溢出或关键操作不可达。
- `typecheck`、`lint`、全量测试、生产构建和 Sites Worker 测试全部通过。

## 验证路径

1. 运行现有测试建立六面盒型基线。
2. 先为状态迁移、类型切换、互斥封口和袋体厚度编写失败测试。
3. 为自立袋轮廓、白色风琴底、圆弧封边、圆角、拉链和吸嘴几何合同编写测试。
4. 运行 typecheck、lint、全量测试、生产构建和 Sites Worker 测试。
5. 启动本地应用，在真实桌面与 390×844 浏览器视口完成类型切换、正背上传、袋体厚度、圆角、三种封口、相机和 PNG 导出检查。

## 已知限制

- 模型提供稳定的软包装视觉近似，不模拟内容物重量、真实薄膜碰撞或动态褶皱。
