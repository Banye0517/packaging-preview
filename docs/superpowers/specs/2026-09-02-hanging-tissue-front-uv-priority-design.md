# 悬挂抽纸正面 UV 优先设计

## 目标

消除悬挂抽纸正视图右边缘出现的右侧贴图色线，同时保留模型几何、四面原生 UV、斜视效果和用户贴图参数。

## 根因

供稿的正面 UV 最大 U 为约 `0.31110`，右侧 UV 最小 U 为约 `0.30865`，两者在 2048 atlas 上重叠约 5 像素。当前 atlas 先画正面、最后画右侧，导致右侧在重叠区覆盖正面。左侧 UV 与正面不重叠，因此左边没有同样问题。

## 方案

保持四面图片各自的裁切区域不变，只调整 atlas 的绘制层级：先画左右侧，再画正背面。正面因此拥有正面/右侧重叠区；背面同样优先于相邻侧面，行为保持对称。

不修改模型顶点、UV 坐标、材质可见性、图片变换或尺寸补偿。

## 验收

- 四面都上传时，atlas 的绘制顺序为侧面在前、正背面在后。
- 正面覆盖与右侧重叠的 UV 区域。
- 原有 UV 提取、尺寸补偿和裁切测试继续通过。
