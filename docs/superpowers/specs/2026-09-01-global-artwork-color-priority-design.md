# 全盒型印刷贴图原图颜色优先设计

## 目标

所有包装盒型的普通印刷贴图以用户上传图片的 sRGB 颜色为准。3D 预览和透明 PNG 导出不得再通过场景灯光、环境反射、材质底色、tone mapping 或人为饱和度补偿改变图片整体颜色。

该规则覆盖当前五类包装：六面盒型、自立袋、内包装1、内包装2和悬挂抽纸，并作为以后新增盒型的默认印刷材质规则。

## 已确认原则

- 普通印刷贴图使用不受场景灯光影响的颜色直出材质。
- 上传纹理继续声明为 sRGB，材质基色固定为纯白，`toneMapped` 关闭。
- 不增加亮度、饱和度、对比度或色温修正滑块，不用经验参数伪装色彩准确。
- 预览与透明 PNG 导出共用同一套印刷材质，因此颜色规则一致。
- 允许纹理缩放过滤和透明混合造成正常的边缘像素差异；目标是消除整图洗白、压灰、偏色和降饱和。

## 材质边界

只替换承载用户普通图片的印刷表面：

- 六面盒型的六个贴图面。
- 自立袋的正面和背面贴图层。
- 内包装1的完整 UV 贴图层。
- 内包装2的正面和背面贴图层。
- 悬挂抽纸的正面、背面、左侧和右侧贴图层。

以下内容继续使用受光材质，不改为颜色直出：

- 白色结构余面、封边、拉手、拉链、吸嘴、底部风琴和抽出纸。
- 接触阴影、场景灯光和环境光。
- 金箔、银箔、镭射、局部 UV、击凸/压凹等工艺覆盖层。工艺本身需要反射和明暗变化，但其蒙版位置不改变。

这样印刷图案颜色以原图为准，模型的空间感仍由几何轮廓、侧面透视、白色结构、工艺层和接触阴影提供。代价是普通印刷图案自身不再随模型转动产生明显的受光明暗变化。

## 统一实现

新增一个共享印刷材质策略，返回纯白、`toneMapped: false` 的 `MeshBasicMaterial`，并由五个盒型渲染器共同使用。共享纹理绑定函数接受承载 `map` 的通用材质类型，不再限定 `MeshStandardMaterial`。

以后新增盒型时：普通上传图片默认接入共享颜色直出材质；只有结构层和明确的特殊工艺层可以使用 Standard/Physical 材质。若某一盒型需要偏离，必须在该盒型规格中单独说明原因。

## 完成标准

1. 五种盒型的普通印刷材质均使用统一颜色直出策略。
2. 悬挂抽纸删除临时 emissive 补偿，不再通过受光材质调色。
3. 结构面、阴影和工艺层仍保持现有受光效果。
4. 同一张高饱和度 sRGB 图片在上传原图、3D 正视面和透明 PNG 导出中不再出现明显整体洗白、压灰或降饱和。
5. 现有 UV、贴图变换、盒型尺寸、贴图尺寸锁定和工艺功能不受影响。

## 验证

- 共享材质单元测试验证材质类型、纯白基色、sRGB map 和关闭 tone mapping。
- 五个渲染器各有静态或组件契约测试，防止重新使用受光印刷材质。
- 运行相关材质/盒型测试、类型检查、lint 和生产构建。
- 使用同一张代表性高饱和度图片做一次预览和透明 PNG 导出对比；若浏览器文件上传仍不可自动控制，明确记录该视觉验收限制，不用构建结果代替。
