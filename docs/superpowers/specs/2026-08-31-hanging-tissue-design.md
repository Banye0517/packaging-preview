# 悬挂抽纸盒型设计

## 目标

新增独立盒型“悬挂抽纸”。它使用用户最新提供的单个 `悬挂纸巾1.gltf`，以 `未标题_3.psd` 中已分开的四个 UV 岛作为正、背、左、右贴图事实来源。同时修正模型贴地和缩放中心，避免放大后产品跑出画面。

## 已确认范围

- 只使用一个 glTF 模型；不维护“有纸”和“无纸”两套模型。
- 上传区只有四个明确面：正面、背面、左侧、右侧；不提供顶部和底部上传。
- 每张图片上传后按该面的实际表面自动校准，不需要为基础贴合而手动旋转、缩放或移动。
- 每面保留独立的等比缩放、水平位置、垂直位置、旋转、水平拉伸、垂直拉伸和重置。
- 上述调整默认收起，仅作为“高级调整”中的特殊图片微调；范围沿用内包装现有约束。
- 模型节点 `纸.1` 作为抽出纸张，提供“显示抽纸”开关；关闭时只隐藏该节点，不替换包装主体或其他内纸网格。
- 盒型继续沿用内包装的宽度、高度、0°/90°/180°模型方向、保存/打开、撤销/重做、透明 PNG 导出与左侧固定预览布局。
- 不新增顶部、底部贴图和任何表面工艺功能，不改动已有四种盒型的逻辑与配置。

## 模型、UV 与定位事实

新 glTF 的主体根节点为 `悬挂抽纸155`，包含两个包装主体网格；`纸.1` 是同一 scene 下的独立根节点。新文件不再包含旧模型的 `悬挂抽纸开` / `悬挂抽纸` 重复层级，因此运行时应克隆新主体和 `纸.1`，再用 `showPulledSheet` 控制纸张可见性。

新供稿的 `TEXCOORD_0` 与 PSD 一致，包含两个大面岛和两个窄侧面岛。运行时保留原生 UV，以三角形 UV 重心所在岛分离网格，再结合对应三角形的外向法线校准正、背、左、右标签。不得再将整个模型按法线强制平面投影到 0–1；这会把顶部、折叠、内部和底部曲面误归到可印刷面。四张用户图片只能写入各自 UV 岛，岛外保持白色，不平铺、不补边、不跨岛。

定位不使用写死的位移。模型载入后计算完整可见内容的包围盒，水平中心对齐场景原点，最低点对齐产品接触地面。宽高缩放必须围绕这个底部锚点，相机 target 对准缩放后的视觉中心，使放大、缩小和重置视图都不会让产品向上漂移或被裁掉。

## 状态与交互

新增 `hanging-tissue` 包装类型及其独立状态：四面图片、四面变换、当前选中面、宽高、模型方向、`showPulledSheet`。四面素材和变换不得相互影响。

每张上传图片先经过现有格式、尺寸和解码校验。默认变换为等比缩放 `100%`、位置 `0%/0%`、旋转 `0°`、水平/垂直拉伸 `100%`；重置恢复这些默认值后，再由面级映射层完成固定校准。贴图不平铺、不补边、不变形；只有用户主动使用独立拉伸时才改变该面图片的横纵比例。

## 错误处理与兼容

模型缺少可打印主体、位置、法线、索引，或任一四面无法形成有效表面区域时，开发与测试环境必须明确报错，不能静默回退为随意投影。旧项目载入时迁移到新增的状态版本，已有盒型的状态和预览不改变。

## 验收标准

- 选择“悬挂抽纸”后可看到模型、正背左右四个上传入口和抽纸显示开关；没有顶部、底部入口。
- 用四张颜色、方向均不同的测试图上传后，默认即分别贴合新模型的对应原生 UV 岛；转动模型时不串到相邻面、顶底折叠、内部或抽出纸张。
- 默认状态下产品底部与接触阴影重合；调整宽高、放大相机或执行视图重置后仍保持贴地并完整入画。
- 不展开“高级调整”时页面只显示上传和必要控制；展开后六项微调与重置齐全，且仅影响当前面。
- 开关能即时隐藏/显示 `纸.1`，包装主体不闪烁、不重载，也不会出现第二个重复模型。
- 宽高、方向、保存/打开、撤销/重做和透明 PNG 导出均包含该盒型的当前状态。
- 自动化测试覆盖新模型节点、四个原生 UV 岛的独立性、面标签校准、底部锚定、贴图变换、纸张节点可见性、状态迁移及配置序列化；类型检查、lint、完整测试、生产构建与真实浏览器四面上传验证通过。

## 取舍

选择“新单模型 + 原生 UV 岛 + 动态底部锚定”。这直接使用用户已在 PSD 中完成的四面分区，不再从曲面法线猜测印刷区；同时模型尺寸改变后仍使用实际包围盒定位，避免针对某一尺寸写死位移。法线只用于标注四个 UV 岛的物理朝向，不再改写 UV。
