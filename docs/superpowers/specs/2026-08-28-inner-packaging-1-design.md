# 内包装1设计说明

## 目标

在不修改六面盒型和现有自立袋行为的前提下，新增第三种包装类型“内包装1”。它使用用户提供的 `内包装1.gltf`，上传一张完整 UV 贴图。

## 已确认范围

- 包装类型为 `inner-packaging-1`，界面名称为“内包装1”。
- 模型来源为用户提供的 `内包装1.gltf`。
- 仅显示真实袋体，排除名为“大概尺寸”的辅助网格。
- 保持模型原始厚度、底部、封边和鼓起形态。
- 设置仅包含袋宽和袋高，不提供厚度、底部深度、圆角、拉链或吸嘴。
- 一张完整 UV 图片和尺寸独立存储，不与自立袋共用状态。
- 完整 UV 图片支持 50%–300% 整体缩放、水平/垂直 -100%–100% 移动、-180°–180° 旋转、水平/垂直 50%–300% 拉伸和一键重置；露出区域填白，不平铺或拉伸边缘。
- 六面盒型和现有自立袋的模型、参数、贴图行为保持不变。

## 数据与兼容性

项目状态升级为版本 6，`innerPackaging1` 包含一张完整 UV 贴图、宽度、高度及贴图变换参数。旧项目打开时自动补齐默认变换；短暂使用过的版本 3 正面贴图迁移为单张 UV 贴图。

## 模型处理

加载 glTF 后按节点名选择主袋体，并明确忽略“大概尺寸”。复制主袋体几何体并应用世界矩阵；将模型由 Z 轴朝上转换为场景 Y 轴朝上。几何体按用户宽高等比调整：X 轴按宽度，Y/Z 共同按高度，保留原始深高比。

保留 glTF 自带 UV，不再生成正背面平面 UV。上传的一张完整贴图直接覆盖整个主袋体，包括正面、背面、封边和底部。

## 验收标准

1. 包装类型有且仅有六面盒型、自立袋、内包装1三项。
2. 切换到内包装1时首页显示提供的 glTF 主袋体，辅助尺寸网格不可见。
3. 只显示一个完整 UV 贴图上传入口，上传后覆盖整只袋体。
4. 内包装1设置只显示宽度和高度。
5. 上传后可调整缩放、位置、旋转与水平/垂直拉伸，重置恢复 100%/居中/0°，空白区域为白色。
6. 三种包装类型的贴图和设置互不覆盖。
7. 旧版本项目可以打开，并自动获得默认内包装1状态。
8. 单元测试、类型检查、lint、构建和 Sites 测试通过，并完成真实浏览器视觉检查。
