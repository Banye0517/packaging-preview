# 悬挂抽纸中段盒身圆角设计

## 目标

为悬挂抽纸增加独立的盒身圆角参数。默认值为 `0 mm`，完全保持当前模型外形；用户增加圆角后，只改变中段盒身四条竖向转角，不改变顶部提手和下方独立纸巾。

## 交互与数据

- 在“悬挂抽纸设置”的宽、高、厚控件后增加“盒身圆角（毫米）”。
- 默认值为 `0`。
- 状态字段为 `hangingTissue.radius`，随项目文件保存。
- 旧项目缺少该字段时迁移为 `0`，不改变已有项目外观。
- 输入下限为 `0`，有效上限为 `min(width, depth) / 2`；尺寸缩小导致现有圆角超过上限时，渲染和状态统一限制到新上限。

## 几何实现

- 复用现有 `deformHangingTissueGeometry` 中段变形管线。
- 在宽度、厚度和高度变形后，将处于中段作用范围内的横截面映射到指定半径的圆角矩形。
- `radius = 0` 时不执行圆角映射，顶点位置与当前实现一致。
- 圆角权重沿用现有 `bodyMinY`、`bodyMaxY`、`connectorMaxY` 区域：中段完整生效，顶部连接区逐渐衰减，提手区域为零。
- 独立节点 `纸.1` 不进入盒身变形流程，因此位置、形状和尺寸不受圆角影响。
- 基础受光层与透明原色贴图层共享同一变形后几何，避免贴图与盒身分离。

## 贴图行为

- 圆角只改变模型表面，不修改用户上传图片的宽高比例、缩放、偏移、旋转或拉伸参数。
- 现有贴图尺寸锁定逻辑保持不变。
- 图片沿圆角表面弯曲；没有图片覆盖的区域继续显示受光底材，不填充纯白。

## 验收标准

- 默认 `0 mm` 与当前悬挂抽纸外形一致。
- 增加圆角后，盒身四条竖向转角连续变圆，正背左右贴图保持贴合。
- 顶部提手没有被压缩、拉伸或圆角化。
- 下方纸巾没有被压缩、拉伸或圆角化。
- 圆角无法超过当前宽度或厚度允许的几何上限。
- 保存并重新打开项目后圆角值保持；旧项目加载后为 `0 mm`。
- 相关状态、迁移、控件和几何测试通过，类型检查、lint 与构建通过。

## 不在范围内

- 不给其他盒型增加或修改圆角能力。
- 不改变悬挂抽纸的相机、灯光、阴影、颜色策略和贴图调整 UI。
- 不重建 glTF，不修改顶部提手或下方纸巾模型。
