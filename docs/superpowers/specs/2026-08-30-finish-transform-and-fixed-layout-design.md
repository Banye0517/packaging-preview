# 金属工艺、纹理变换与固定预览设计合同

## 范围

- 提升烫金和烫银的金属反射、明暗对比与高光可见性。
- 工艺蒙版的位置、旋转和等比缩放只改变覆盖轮廓，不带动金属膜或镭射膜的纹理坐标。
- 桌面端左侧 3D 预览固定，只有右侧设置区独立滚动。
- 不修改现有包装类型、上传流程、参数范围或移动端上下布局。

## 材质设计

- 烫金和烫银使用高金属度、低粗糙度、增强环境反射、清漆高光和静态金属明暗膜。
- 金属膜与镭射膜使用盒面自身的固定 0–1 UV，不读取蒙版的 transform。
- 蒙版继续使用居中、等比的 scale，水平和垂直偏移与旋转仅修改 alphaMap。
- 金属膜和镭射膜在蒙版变换时不重建，防止高光、彩虹或拉丝方向跟着图案移动。

## 布局设计

- 大于 760px 时，`html` / `body` / `#root` / `.app-shell` 固定为一屏高度并禁止页面滚动。
- `.workspace` 占用工具栏以下的剩余高度；`.preview-stage` 不滚动；`.settings-panel` 使用 `overflow-y: auto`。
- 小于等于 760px 时恢复文档滚动和现有上下布局。

## 验收标准

- 黑白蒙版在烫金和烫银下都显示可辨认的亮部、暗部和镜面高光。
- 分别改变蒙版缩放、位置和旋转后，轮廓等比变换，金属膜/镭射膜的明暗和色序保持在盒面原位。
- 桌面端滚动右侧至底部时，左侧 3D 的位置和尺寸不变。
- 移动端页面仍可正常上下滚动。
