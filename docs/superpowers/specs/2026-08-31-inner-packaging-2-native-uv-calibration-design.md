# 内包装2原生 UV 自动校准设计

## 目标

修正内包装2上传正反面设计图后仍需手动旋转、缩放和移动才能贴合的问题。上传图片必须先按 `inner-packaging-2.gltf` 的真实正反面 UV 岛自动映射；所有调整控件只作为可选微调，不能承担基础校准。

## 已确认范围

- 左侧 UV 岛对应正面，右侧 UV 岛对应背面。
- 上传后默认方向正确、位置居中，并按对应 UV 岛自动贴合。
- 保留等比缩放、水平位置、垂直位置、旋转、水平拉伸、垂直拉伸和重置。
- 调整区默认收起，命名为“高级调整”；用户主动展开后才显示控件。
- 重置恢复自动校准后的默认状态，而不是恢复当前写死的补偿旋转。
- 正反面调整相互独立；一面的图片不能越界污染另一面。
- 不修改模型几何、宽高、模型方向、其他包装类型或工艺功能。

## 根因

当前纹理合成把 1024×1024 画布机械分成左右两个 512×1024矩形，并用 `aspect-fit` 把图片绘制进半幅矩形。这个矩形不是模型 UV 岛的真实边界，因此默认图片不能准确覆盖模型表面。

当前合成层还无条件执行 `Math.PI` 旋转。该补偿被写进所有图片的默认绘制流程，使用户上传正常方向的设计图后仍可能需要手动旋转。基础映射和用户微调没有分层，是本次问题的直接原因。

## 映射方案

从 glTF 唯一网格读取顶点位置、法线、索引和 `TEXCOORD_0`。以模型正反表面的朝向分类三角形，再分别收集对应三角形使用的 UV 坐标，计算正面和背面的真实 UV 包围区域。左右位置只用于验证 PSD 约定，不再作为固定的 `0–0.5` 与 `0.5–1` 绘制边界。

纹理合成按每面的真实 UV 区域建立局部绘制坐标：先应用模型需要的固定方向校正，再执行用户的缩放、位移、旋转和水平/垂直拉伸。固定方向校正属于模型映射配置，不写入用户变换值，也不显示为用户已经旋转了图片。

正反面分别裁切到自己的 UV 区域，画布其他部分填白；禁止平铺和边缘延展。模型继续直接使用原生 UV，不修改 glTF，不重建 UV。

## 状态与交互

现有正反面素材、选择面、等比缩放、位移和旋转状态继续兼容。每面新增独立的水平拉伸和垂直拉伸值，默认均为 `100%`，允许范围保持 `50%–300%`。旧项目缺少这两个字段时自动补齐为 `100%`。

高级调整默认收起。展开后显示：

- 等比缩放：50%–300%
- 水平位置：-100%–100%
- 垂直位置：-100%–100%
- 旋转：-180°–180°
- 水平拉伸：50%–300%
- 垂直拉伸：50%–300%
- 重置贴图

上传新图不会继承用于修正旧错误映射的隐式补偿。重置将六项用户变换恢复为 `100%、0%、0%、0°、100%、100%`，然后由映射层应用模型固定校准。

## 错误处理

模型缺少 UV、索引或无法区分正反面 UV 区域时，在测试和开发环境明确失败，不回退到左右半画布的旧逻辑。图片校验继续沿用现有 PNG、JPG、WebP、尺寸与解码规则。

## 验证与验收

- 使用不同颜色和带方向文字的正反面测试图，在默认变换下上传即正确贴合。
- 正面只显示在模型正面，背面只显示在模型背面；转到侧边和封口区域时不串图。
- 默认状态不需要用户旋转、缩放、移动或拉伸。
- 展开高级调整后，六项控制分别生效，正反面互不影响。
- 水平或垂直拉伸只改变用户选中的图片，不改变模型形状。
- 重置恢复经过原生 UV 校准的正确默认显示。
- 保存、打开、撤销、重做和旧项目迁移保持可用。
- 自动化测试覆盖 UV 区域提取、固定方向校正、默认映射、六项变换和旧项目迁移。
- 类型检查、lint、完整测试、生产构建和真实浏览器上传验证通过。

## 取舍

不采用写死 UV 数值，因为模型重新导出后容易再次错位；不继续使用左右各半的粗略画布，因为它无法表达 UV 岛留白和真实边界。运行时只需在模型加载后计算一次 UV 区域，成本很低，且能让模型文件继续成为唯一视觉事实来源。
